## serial relation inducing a total partial function — <span lang="ar" dir="rtl">تسلسلية؛ كلية</span>

- **ID / الرقم:** `locale-ar-chosen-21e90fab9c46cec8`
- **Sense / المعنى:** A right-unique relation R⊆A×B defines a partial function A⇀B. Seriality adds an output witness in B for every input in A, making that function total. This neither requires nor implies surjectivity onto B.
- **Why this choice / سبب الاختيار:** Current assessment (2026-09-06; open to correction): New independent assessment (2026-09-06): retain تسلسلية for the displayed ∀x∈A∃y∈B condition and كلية for the resulting defined-everywhere function. The preceding uniqueness hypothesis is essential: seriality alone permits more than one output and therefore does not by itself define a function. A=a, B=b,c, R=(a,b) is right-unique and serial, so its function is total but not surjective. The retained long Arabic headword is a summary; the literal technical words in the proposition are تسلسلية and كلية. These clauses justify the conceptual distinction but do not establish a cross-regional preference for تسلسلية over other terminology. This assessment is provisional and open to correction; it does not reconstruct the original translator's deliberation or claim official dictionary attestation. Independent admission readback (2026-09-06): Both registers separately state right-uniqueness before seriality. A singleton input with two possible codomain values shows totality without surjectivity; two outputs for that same input show why seriality alone is insufficient. The literal labels تسلسلية and كلية are supported in Classical as well as MSA.
- **Assessment provenance / توثيق التقييم:** New assessment, not a claim about the original translator's reasoning. [Original explanation and checked source witnesses / التعليل السابق وشواهد المصدر](../../../evidence/provenance/locale-ar/expert-review-amendments/questions-next10-20260906.json).
