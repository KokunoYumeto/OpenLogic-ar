## self-membered; non-self-membered set — <span lang="ar" dir="rtl">عضوًا في نفسها؛ غير منتمية إلى نفسها</span>

- **ID / الرقم:** `locale-ar-chosen-59f7d69426d8abe8`
- **Global priority rank / score:** #806 / 20
- **Sense / المعنى:** Self-membership is x∈x and non-self-membership is x∉x. Russell's contradiction rules out a set collecting exactly all non-self-membered sets. It does not by itself establish that no set can belong to itself.
- **Why this choice / سبب الاختيار:** Current assessment (2026-09-06; open to correction): New independent assessment (2026-09-06): retain the explicit membership wording because the property concerns ∈, not subset inclusion or ordinary containment. The displayed comprehension and its R∈R iff R∉R contradiction supply the meaning and scope. ## successor function; f-closed; closure under f; Dedekind algebra — <span lang="ar" dir="rtl">دالة اللاحق؛ منغلقة تحت f؛ الإغلاق تحت f؛ جبر ديديكند</span>

- **Sense / المعنى:** The successor function generates the natural-number sequence from numerical 0. For an endofunction f:A→A, an f-closed subset X contains f(x) whenever it contains x. ## symmetric; anti-symmetric; asymmetric; not symmetric — <span lang="ar" dir="rtl">متناظرة؛ مضادّة للتناظر؛ لا تناظرية؛ غير متناظرة</span>

- **Sense / المعنى:** Symmetry requires Rxy⇒Ryx for every x,y. Antisymmetry requires (Rxy and Ryx)⇒x=y; it permits, but does not require, reflexive pairs. The Arabic prose explicitly distinguishes مضادّة للتناظر from غير متناظرة; keeping لا تناظرية separate is likewise essential, not stylistic variation.
