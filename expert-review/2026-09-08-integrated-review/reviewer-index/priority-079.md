## modular arithmetic; congruence modulo n — <span lang="ar" dir="rtl">الحساب بترديد عدد</span>

- **ID / الرقم:** `locale-ar-chosen-21d39aea9b39f333`
- **Global priority rank / score:** #775 / 20
- **Sense / المعنى:** For a fixed positive modulus n, a≡ₙb means that division by n gives equal remainders, equivalently a−b=kn for an integer k. This is a congruence relation, not numerical equality; its residue classes are the objects subsequently counted.
- **Why this choice / سبب الاختيار:** Current assessment (2026-09-06; open to correction): New independent assessment (2026-09-06): retain الحساب بترديد عدد as the actual Arabic name used in the example. The retained second headword التطابق بترديد n is an explanatory label, not a phrase found in the inspected MSA/Classical example; the relation is there expressed by ≡ₙ and its definition. The integer requirement on k allows negative differences: 1 and 4 are congruent modulo 3 with k=−1. The initial source wording groups a,b,n under PosInt, while the later quotient is over Nat and explicitly uses the class of 0. That is a shared domain-scope question worth making explicit, not evidence for inventing a dictionary-approved congruence label. This assessment is provisional and open to correction; it does not reconstruct the original translator's deliberation or claim official dictionary attestation. Independent admission readback (2026-09-06): The example explicitly places k in Int, so the negative-difference case supports congruence rather than equality. The a,b,n positivity wording and later Nat/zero class genuinely deserve a scope question; do not certify the unused second Arabic headword as printed prose.
- **Assessment provenance / توثيق التقييم:** New assessment, not a claim about the original translator's reasoning.
