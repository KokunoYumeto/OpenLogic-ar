## potent set — <span lang="ar" dir="rtl">مجموعة مقتدرة</span>

- **ID / الرقم:** `TERM-POTENT-SET`
- **Sense / المعنى:** A set A containing every subset of every member y of A: for all x, if some y ∈ A contains x as a subset, then x ∈ A.
- **Why this choice / سبب الاختيار:** Current assessment (2026-09-06; open to correction): Provisionally retain مجموعة مقتدرة only as a defined local coinage. The source itself says 'potent' lacks standard terminology; the defining formula, not an ordinary sense of power or capability, determines the property. The compact adjective is reusable, but an explanatory gloss such as 'contains every subset of each of its members' is more transparent at first use. This audit does not claim any dictionary attestation or equate the property with closure under subsets of A itself.
- **Assessment provenance / توثيق التقييم:** New assessment, not a claim about the original translator's reasoning. [Original explanation and checked source witnesses / التعليل السابق وشواهد المصدر](../source-snapshot/repo/evidence/provenance/locale-ar/expert-review-amendments/semantic-first20-20260906.json).
