# Modus ponens is affirmation of the antecedent, not the consequent

The frozen English names *modus ponens* alongside `A, A → B ⊢ B`. This affirms
the antecedent. Affirming the consequent would instead infer `A` from `B` and
`A → B`, which is not generally valid. Both Classical passages already had the
correct rule name; that substantive correction had not reached the shared MSA
source used by the International and Machrek versions.

Only the two labels were changed. Formulas and proofs, including the earlier
OLP-0079 proof repair, remain untouched. Reversing each label replacement
recovers the exact previous file hash.
