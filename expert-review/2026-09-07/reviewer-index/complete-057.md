## sequent — <span lang="ar" dir="rtl">تتابعية</span>

- **ID / الرقم:** `RETRO0051-0100-sequent`
- **Sense / المعنى:** Two-sided sequent Γ ⟹ Δ whose antecedent and succedent are finite, possibly empty, sequences of sentences; not an ordinary sequence.
- **Why this choice / سبب الاختيار:** Current assessment (2026-09-06; open to correction): This new assessment provisionally retains تتابعية as a short name because the definition immediately distinguishes the two-sided expression from the two sequences it contains. The succession-related wording alone does not express entailment, so the displayed definition is essential. تعاقبية is an unverified competing coinage, not an established superior term. This does not claim to reconstruct the original translator's deliberation.
- **Assessment provenance / توثيق التقييم:** New assessment, not a claim about the original translator's reasoning. [Original explanation and checked source witnesses / التعليل السابق وشواهد المصدر](../source-snapshot/repo/evidence/provenance/locale-ar/expert-review-amendments/semantic-first20-20260906.json).
- **Useful alternatives / البدائل المفيدة:** تعاقبية — possible alternative — May be closer morphologically but is not the current choice.; قضية تتابعية — possible explanatory alternative — Too long for dense proof trees.; سِكْوِنت — not selected — Transliteration offers little semantic guidance.
