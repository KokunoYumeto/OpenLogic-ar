\olsection{حالات التوقف}

\begin{explain}
جعلنا توقف الآلة ناشئًا عن عدم وجود تعليمة تنفذها. غير أن الشائع في بعض تمثيلات آلات تورنغ تخصيص \emph{حالة توقف} $h$، مع $h \in Q$.

ومعنى ذلك أن الآلة، إذا قضت عملها فتهيأت لقبول الدخل أو فرغت من كتابة الخرج، تدخل الحالة~$h$ وتقف. وقد يخصص لها حالتا توقف: إحداهما للقبول، والأخرى للرفض.
\end{explain}

\begin{ex}\emph{حالات التوقف}.
ولنوضح الأمر بتعديل آلة الزوجية. فقد كانت تقف في الحالة~$q_0$ عند الدخل الزوجي؛ فنزيد الآن تعليمة تنقلها إلى حالة التوقف المخصوصة.
\[
\begin{tikzpicture}[->,>=stealth',shorten >=1pt,auto,node distance=2.8cm,
                    semithick]
  \tikzstyle{every state}=[fill=none,draw=black,text=black]

  \node[initial, state]         (A)                     {$q_0$};
  \node[state]         (B) [right of=A] {$q_1$};
  \node[state]         (C) [below of=A] {$h$};

  \path (A) edge [bend left] node {\TMtrans{\TMstroke}{\TMstroke}{R}} (B)
        edge node {\TMtrans{\TMblank}{\TMblank}{N}} (C)
        (B) edge [loop above] node {\TMtrans{\TMblank}{\TMblank}{R}} (B)
            edge [bend left] node {\TMtrans{\TMstroke}{\TMstroke}{R}} (A);
\end{tikzpicture}
\]

ونزيد في التعديل: كانت الآلة، إذا تبين لها فردية الدخل، تدور بلا توقف. فنجعل لها حالة \emph{رفض} عوضًا عن ذلك، ونستبدل بالتعليمة الدائرة تعليمة تنقلها إلى حالة الرفض~$r$.
\[
\begin{tikzpicture}[->,>=stealth',shorten >=1pt,auto,node distance=2.8cm,
                    semithick]
  \tikzstyle{every state}=[fill=none,draw=black,text=black]

  \node[initial,state]         (A)                     {$q_0$};
  \node[state]         (B) [right of=A] {$q_1$};
  \node[state]         (C) [below of=A] {$h$};
  \node[state]         (D) [below of=B] {$r$};

  \path (A) edge [bend left] node {\TMtrans{\TMstroke}{\TMstroke}{R}} (B)
        edge node {\TMtrans{\TMblank}{\TMblank}{N}} (C)
        (B) edge node {\TMtrans{\TMblank}{\TMblank}{N}} (D)
            edge [bend left] node {\TMtrans{\TMstroke}{\TMstroke}{R}} (A);
\end{tikzpicture}
\]
\end{ex}

\begin{explain}
ولهذا التخصيص فائدة؛ إذ يظهر به قبول المدخلات ورفضها ظهورًا صريحًا. لكنه لا يزيد شيئًا في القدرة الحسابية للآلة. وللاكتفاء بمعنى التوقف الأول مزاياه أيضًا؛ فإن تعريفنا السابق ييسر عرض برهان \emph{مسألة التوقف} ويقرب معناه إلى الحدس. ولذلك نثبت على التعريف الأصلي.
\end{explain}
