# Modus ponens: missed correction carried into both MSA versions

New assessment, 6 September 2026. This is not a reconstruction of the original
translator's private reasoning. The wording remains open to expert correction.

| What to check | Exact location | Wording |
|---|---|---|
| English rule | OLP-0497, Axiomatic derivations, definition, third list item; source lines 25–26 | modus ponens |
| International and Machrek MSA | Same definition, [source lines 24–25](../../../source/locale/ar/content/intuitionistic-logic/introduction/axiomatic-derivations.tex#L24) | **بقاعدة إثبات المقدَّم**, corrected from بقياس الخلف |
| Classical Arabic | Same definition, [source lines 24–25](../../../source/locale/ar-classical/content/intuitionistic-logic/introduction/axiomatic-derivations.tex#L24) | بقاعدة إثبات المقدَّم — already correct; unchanged |

Why: the definition derives `A_i` from `A_j` and `A_j → A_i`. The old MSA
wording named proof by contradiction, which is a different rule. The Classical
wording had already repaired this, but the repair had not reached the shared
MSA source. Both existing notation versions use that source. No formula,
Classical register, or RTL formula presentation was changed by this correction.

Expert question: **Is قاعدة إثبات المقدَّم the best established Arabic term
for modus ponens?** If a specialist dictionary prefers another exact term,
please suggest it with a reference. القياس الاستثنائي was not selected because
it can cover a broader family of inferences. We do not claim an official
dictionary attestation for our choice.

The previous review's passing verdict missed this MSA defect. That original
record is preserved; this dated correction explicitly qualifies it.
