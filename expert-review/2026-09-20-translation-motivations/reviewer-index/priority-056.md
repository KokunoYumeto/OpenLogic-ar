## surjective functions — <span lang="ar" dir="rtl">وتسمى هذه الدوال شاملة، وصورتها</span>

- **ID / الرقم:** `semantic-propagation-20260907:AR-OLP-0022-CLASSICAL-SURJECTIVE-OPENING-20260907`
- **Global priority rank / score:** #538 / 62
- **Sense / المعنى:** Each function takes every codomain member as a value; the adjective describes the functions, not a category object.
- **Why this choice / سبب الاختيار:** The old masculine subject هذا الصنف is followed by the shared feminine adjective شاملة.
