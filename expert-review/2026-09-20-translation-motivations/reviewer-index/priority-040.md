## enumerable — <span lang="ar" dir="rtl">فلكل مجموعة غير خالية</span>

- **ID / الرقم:** `semantic-propagation-20260906:0033-P1`
- **Global priority rank / score:** #393 / 80
- **Sense / المعنى:** A surjection from positive integers exists for every nonempty enumerable set, not for the empty enumerable set.
- **Why this choice / سبب الاختيار:** New independent assessment dated 2026-09-06; not a reconstruction of the original translator's deliberation. Inherited-source qualification: this makes the mathematical qualification or logical scope explicit, rather than claiming only a lexical mistranslation. Previous MSA wording: فلكل مجموعة. English and MSA omit nonemptiness from the universal existence claim. Classical already adds it and a disclosed source-correction note.
