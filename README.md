## معنى الاكتمال

يحتوي كل ملف PDF على جميع ملفات المحتوى الإنجليزي المتتبّعة البالغ عددها 722 ملفًا في صورة عربية. يصل مسار الكتاب الاعتيادي في المصدر إلى 642 وحدة؛ أما الوحدات الثمانون الأخرى، ومنها مشغلات وفصول بديلة، فأُدرجت داخل كل ملف في قسم تقني لاحق. لذلك لا توجد «نسخة ناقصة» ولا حاجة إلى تنزيل ملحق منفصل.

الملفان لهما النص العربي والمصادر وصيغ الرياضيات نفسها. الفرق عرضي فقط:

- **الدولي:** تظهر أرقام الصيغ الرياضية بالأشكال `0–9`.
- **المشرقي:** تظهر أرقام الصيغ الرياضية بالأشكال العربية الهندية `٠–٩`، مع إبقاء ترتيب الصيغ من اليسار إلى اليمين، والمتغيرات اللاتينية واليونانية، والرموز، وعناوين URL، والرموز المصدرية بلا تغيير دلالي.

تثبت بوابات التحقق إغلاق 722/722، وسلامة UTF-8 وUnicode، والمحافظة على تيارات صفحات المكوّنات والنص المستخرج، ووجود 3154 رابطًا في كل ملف مع عدم وجود روابط خارجية بين ملفات أو أهداف داخلية مكسورة. أُعيد تجميع الملفين مستقلاً وتطابقت البايتات تطابقًا تامًا، كما فُحصت بصريًا صفحات العنوان والانتقال والنهاية في الملفين.

المقاس US Letter عمودي. الملفان ثابتَا التخطيط وغير موسومين بنيويًا، ولا يُقدَّمان على أنهما متوافقان مع PDF/UA. حُفظت الإصدارات السابقة في سجل الإصدارات.

المؤلف والمنشئ: Open Logic Project. حُفظت هوية المصدر المثبّت في حزمة الأدلة التقنية. المعرّف المفهومي الثابت: [10.5281/zenodo.21921850](https://doi.org/10.5281/zenodo.21921850).

## English

This repository publishes two standalone complete Arabic editions of the pinned Open Logic Project content: one with international mathematical digits and one with Machrek Arabic-Indic mathematical digits. Each PDF contains Arabic coverage for all 722 tracked English content `.tex` files; no companion download is required. The ordinary upstream book graph reaches 642 units, so the remaining 80 tracked units are appended inside each PDF as a technical section.

Both profiles use the same Arabic prose and formula-token source. The Machrek profile changes only the displayed glyphs of mathematical digits to `٠–٩`; it retains LTR formula order, identifiers, Latin/Greek variables, symbols, URLs, and source semantics. Both final PDFs passed structural, link, Unicode, font, deterministic-replay, and rendered-page QA.
